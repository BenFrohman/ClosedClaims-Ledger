# What [Pi] and [S] honestly are

Author: Benjamin Stanley Frohman

X=V(F) subset P^5 contains a plane. Residual cut X cap L_{a,b,c} = Pi union S_{a,b,c}.
S is a smooth quintic surface in a P^3, K_S isomorphic to O_S(1), dimension 2.
Not a fourfold. Not partner Y.

    [Pi] = cl_X(Pi),    [S] = cl_X(S) = h^2 - [Pi].

They hit im(cl_X). Span Q h^2 + Q [Pi] has rank 2. That is special-host algebraicity.
A general sextic has only Q h^2. h^{2,2}=1752 counts complex forms; it is not the rational lattice.
